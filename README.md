# 🏨 Hotel Room Booking System

A simple **Hotel Room Booking System developed in C** as part of the **CSC215 Project** at King Saud University.

The system allows users to create an account, log in, browse available rooms, search by room type, make reservations, view their bookings, and cancel reservations.

## ✨ Features

* User registration and login
* View available hotel rooms
* Search rooms by type:

  * Standard
  * Deluxe
  * Suite
* Book available rooms
* Calculate the total booking cost
* View user bookings
* Cancel existing bookings
* Automatically update room availability

## 🛏️ Room Information

Each room contains:

* Room ID
* Room type
* Capacity
* Price
* Availability status
* Amenities

## 💻 Technologies Used

* **Language:** C
* **Concepts:** Structures, Arrays, Pointers, Functions, Enums, Header Files, and Modular Programming
